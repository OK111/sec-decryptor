    How it works & is it safe?

    Everything runs locally using your browser's built-in Web Crypto. No file or password is ever uploaded — you can even use this page with your network disconnected.

    Solid Explorer's single-file format is:

    • salt(16) · IV(16) · verifier(4) · ciphertext
    • Key = PBKDF2 of your password + salt (HMAC-SHA256, 100001 iters; older files: HMAC-SHA1, 1024)
    • Cipher = AES-256-CTR
    • The 4-byte verifier lets the page tell a wrong password from a good one.

    Decrypted names drop the trailing .sec. This tool handles single-file encryption (encrypted folders, which also scramble filenames, aren't supported yet).
