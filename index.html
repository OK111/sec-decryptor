    How it works & is it safe?

    Everything runs locally using your browser's built-in Web Crypto. No file or password is ever uploaded — you can use this page with your network disconnected.

    Single file (name.ext.sec): salt(16) · IV(16) · verifier(4) · ciphertext.

    Encrypted folder: a container holding a .key file plus files whose names are AES-encrypted and Base64url-encoded. Pick the whole encrypted folder and you'll get a .zip of the decrypted tree.

    • Key = PBKDF2 of your password + salt (HMAC-SHA256 ×100001; older files: HMAC-SHA1 ×1024)
    • Cipher = AES-256-CTR; the 4-byte verifier distinguishes a wrong password from a good one.
